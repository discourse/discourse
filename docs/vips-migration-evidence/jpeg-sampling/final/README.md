Run `bundle exec ruby run.rb` in the coordinator's production benchmark base after installing the pinned bundle with the existing benchmark procedure. This bundle uses the existing geometry benchmark Gemfile and lock, current dirty integration worker/facade sources, and exact extracted legacy geometry/conversion methods. source-manifest.json records HEAD, source SHA256 values and extraction lines; run.rb verifies every copied runtime file before executing.

The companion generates a bounded96×64 RGB pattern with native Vips, then creates JPEG sources with ImageMagick's explicit444/420/422/440 sampling factors atQ89. It covers all five transformations for JPEG sources, including explicit versus inherited quality and both metadata modes for resize/crop. PNG cases cover default92 and explicit89/90 on applicable transformations; downsize uses its existing inherited/default policy. PNG auto-orientation is excluded because that worker and the upload orientation gate require JPEG.

Outputs checkpoint after each case in outputs/results.json. Records include exact JPEG factors from the sandboxed ImageMagick evidence probe, the native header's potentially collapsed sampling description, dimensions, file size, ICC hash, pixel differences and failures. There is no timing claim or post-optimizer stage. Orientation is identity orientation here to isolate encoding; actual rotated-source behavior is covered by the separate rotation tests.

All sources and outputs have unique paths. Original inputs are retained. Landlock is required. The standalone shims supply Rails paths, metadata mode, disabled instrumentation and exception/translation text; transformation options come from exact extracted production methods. 422/440 are measured explicitly and never inferred from the native420 label.
