# Capybara

Capybara is a Discourse plugin. Its product purpose is TO BE DEFINED.

This plugin is based on [the official Discourse plugin skeleton](https://github.com/discourse/discourse-plugin-skeleton) at commit `9c79225314c80e3a5328730c51ff00fa5c7984c8`. Its engine uses the `DiscourseCapybara` namespace to avoid a collision with the Capybara test library.

The `capybara_enabled` site setting controls this plugin independently.
